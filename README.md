# Ferrous

Компилятор собственного языка программирования (`.fer`) → LLVM IR → нативный
исполняемый файл (x86-64).

## Зависимости

- clang++ ≥ 17, CMake ≥ 3.30, Ninja
- **LLVM 17+** (`pacman -S llvm` / `apt install llvm-dev`)

## Сборка

```bash
cmake --preset clang     # конфигурация в каталог build/
cmake --build build      # бинарь build/Ferrous
```

## Запуск

```bash
./build/Ferrous examples/test_arithmetic.fer      # компиляция → ./test_arithmetic
./test_arithmetic                                 # запуск
./build/Ferrous examples/test_arithmetic.fer -o hi   # своё имя выходного файла
```

Без `-o` имя выходного файла берётся из имени исходника
(`foo.fer` → `foo`).

### Диагностические режимы

| Флаг            | Что делает                                            |
|-----------------|-------------------------------------------------------|
| `--dump-tokens` | Печатает поток токенов и завершает работу.            |
| `--dump-ast`    | Печатает AST и завершает работу.                      |
| `--dump-sema`   | Печатает AST с выведенными типами на каждом выражении.|
| `-o <out>`      | Имя выходного исполняемого файла.                     |

При любой ошибке (лексер/парсер/сема/кодоген) компилятор печатает диагностику
в формате `<файл>:<строка>:<столбец>: error: ...` и завершается с кодом 1.

## Pipeline

```
.fer → Lexer → Parser → Semantic → Codegen → LLVM IR → clang++ → executable
```

## CMake-цели

| Цель    | Что делает                                                     |
|---------|---------------------------------------------------------------|
| `build` | Сборка компилятора (по умолчанию).                            |
| `run`   | Компилирует пример и **исполняет** полученный бинарь.         |
| `debug` | Прогоняет диагностические фазы (tokens/ast/sema) над примером.|
| `check` | Запускает весь набор тестов (`run_tests.sh`).                 |
| `clean` | Встроенная цель сборочной системы.                           |

```bash
cmake --build build --target run
cmake --build build --target check
```

## Тесты

`examples/` + раннер `run_tests.sh` (или цель `check`) — три категории:

- `test_*.fer` — позитивные: компилируются и исполняются с кодом 0.
- `err_sema_*.fer` — ошибки **компиляции**: компилятор отвергает программу
  (код 1), а его диагностика содержит подстроку из маркера `// @error: ...`
  в первой строке файла.
- `err_*.fer` (остальные) — рантайм-ошибки: компилируются, но исполнение даёт
  ненулевой код (деление на ноль, выход за границы, panic, assert).

```bash
./run_tests.sh                    # ищет build/Ferrous
./run_tests.sh path/to/Ferrous    # явный путь к компилятору
```

## Возможности языка

- Целые `int8…int64`, `uint8…uint64` (суффиксы, hex/bin-литералы), `float32/64`,
  `bool`, `char` (Unicode-codepoint), `string` (UTF-8).
- Массивы фиксированного размера `[T; N]`, структуры, псевдонимы типов (`type`),
  пространства имён (`namespace`), перегрузка функций.
- Вывод типов в `let`, проверка диапазона литералов на этапе компиляции.
- Управление: `if/else`, `while`, `break`/`continue`, `return`.
- Операторы: арифметика, сравнения, логические, битовые (`& | ^ ~ << >>`), `as`.
- Встроенные функции: `print`/`println` (все типы), `input`, `len`
  (строки **и** массивы), `panic`, `assert`, `exit`, преобразования
  `to_string` / `to_int` / `to_float`.
